## About

Budget Tracker is a simple website made with JavaScript. It helps users keep a record of their daily expenses and understand how much they are spending.

## Features

* Add an expense
* See all expenses
* Edit an expense
* Delete an expense
* Search expenses
* Filter expenses by category and date
* Sort expenses by date and amount
* See total expenses
* Save expenses in LocalStorage
* Works on phone and computer

## Technologies Used

* HTML
* CSS
* JavaScript
* Bootstrap
* LocalStorage

## CRUD

* **Create:** Add an expense
* **Read:** See expenses
* **Update:** Edit an expense
* **Delete:** Remove an expense

## Data Storage

The expenses are saved in **LocalStorage**. So, the data stays even after refreshing the page.

## How to Run

Open the `index.html` file in a browser.

You can also use **Live Server** in VS Code.
